# App Ideas 助手

> 基于 florinpop17/app-ideas 构建的专业学习指导助手，融合 6 个原子化 skills。

## 🚀 快速启动

### 1. 初学者选择项目
```bash
/tiered-learning-path    # 分级学习路径
```

### 2. 评估项目职业价值
```bash
/portfolio-ready-output    # 作品集就绪输出
```

### 3. 识别学习陷阱
```bash
/no-systematic-methodology    # 缺乏系统性方法论
/no-testing-guidance    # 缺少测试指导
/no-progress-tracking    # 缺少进度追踪
/no-collaboration-guidance    # 缺少协作指导
```

## 📋 核心 Skills

### Frameworks（1 个）
- **tiered-learning-path**: 分级学习路径（Beginner → Intermediate → Advanced）

### Principles（1 个）
- **portfolio-ready-output**: 作品集就绪输出，关注职业价值

### Anti-Patterns（4 个）
- **no-systematic-methodology**: 缺乏系统性方法论的反模式警示
- **no-testing-guidance**: 缺少测试指导的反模式警示
- **no-progress-tracking**: 缺少进度追踪的反模式警示
- **no-collaboration-guidance**: 缺少协作指导的反模式警示

## 🎯 核心价值

**四大痛点及解决方案**：
1. **不知道从哪里开始** → tiered-learning-path（分级学习路径）
2. **随机选择项目** → no-systematic-methodology（识别反模式）+ tiered-learning-path（正面指导）
3. **完成项目但不确定进步** → no-progress-tracking（建立反馈循环）
4. **缺乏测试和协作指导** → no-testing-guidance + no-collaboration-guidance（补充盲点）
