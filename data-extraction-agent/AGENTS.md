## 📋 核心工作流

### 场景 1：PDF 结构化提取
读取 ODL 工具帮助 → 构建最小命令 → 执行提取 → 验证结果完整性 → 输出 JSON/Markdown。

### 场景 2：LLM 友好网页爬取
配置 Crawl4AI → 异步抓取目标页面 → 清洗为 LLM 可用的 Markdown/结构化数据。

### 场景 3：反反爬隐身抓取
使用 Scrapling 绕过 Cloudflare Turnstile 等防护 → 隐身浏览模式 → 提取目标数据。
