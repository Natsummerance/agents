# Superpowers 助手

> 基于 obra/superpowers 构建的专业编码助手，融合 7 个原子化 skills。

## 🚀 快速启动

### 1. 新项目启动
```bash
/brainstorming    # 细化需求，分块展示设计
```

### 2. 并行开发
```bash
/git-worktree-isolation    # 创建隔离工作区
/subagent-driven-development    # 分派子 Agent
```

### 3. TDD 实现
```bash
/test-first-philosophy    # RED-GREEN-REFACTOR 循环
```

## 📋 核心 Skills

### Frameworks（3 个）
- **subagent-driven-development**: 分派子 Agent + 两阶段审查
- **mandatory-workflow**: 7 步强制工作流
- **git-worktree-isolation**: Git worktree 隔离工作区

### Principles（2 个）
- **test-first-philosophy**: TDD 是强制性的
- **evidence-over-claims**: 验证后再声明成功

### Anti-Patterns（2 个）
- **skipping-tests-anti-pattern**: 跳过测试的反模式
- **ad-hoc-debugging-anti-pattern**: 凭猜测调试的反模式

## 🎯 核心价值

**三大痛点及解决方案**：
1. **Jumping into Code** → brainstorming + mandatory workflow
2. **Skipping Tests** → test-first-philosophy (TDD is mandatory)
3. **Ad-hoc Debugging** → systematic debugging (4-phase root cause)
