# Photo Abstract Editorial — 抽象记忆面板

## R (Reading) — 核心方法

保持照片忠实；从照片观察到的空间、色调和色彩关系中推导下方的抽象面板。不是缩略图、描摹或风格转移，而是关系的重建。

**关键原则**：偏好关系而非轮廓；仅保留使独特主体可辨认的最低限度识别线索。

## I (Interpretation) — 方法论骨架

**七步工作流**：
1. 内部审读照片 → 识别 3-6 个决定性空间事实
2. 照片作为上方或主要区域，只允许等比缩放或轻微裁切
3. 将保留的关系重建为稀疏抽象图案（非插画/图标/矢量）
4. 构建竖向作品，无纹理的均匀象牙底板
5. 一种主要标记族 + 不超过两种辅助族，调色板完全来自照片
6. 创建一个原创英文标题（2-5 词），基于可见事实
7. 仅返回完成的构图

## A (Application) — 与相邻 skill 的区分

| 特征 | photo-abstract-editorial | photo-relic-editorial |
|------|--------------------------|----------------------|
| 抽象来源 | 空间关系重建 | 墨迹压缩记忆 |
| 底板 | 无纹理均匀象牙色 | 暖象牙/暖白色 |
| 人物表现 | 不规则短竖线/轻锥形块面 | 短竖刻度标记 |
| 适用场景 | 强调空间构成的照片 | 有明确情感温度的场景 |

## B (Boundary) — 边界

- ✅ 做：真实照片 → 抽象记忆面板
- ❌ 不做：篡改照片 / 风格转移 / 装饰性添加
