# Photo Abstract Editorial — 抽象记忆面板

## R (Reading) — 源项目核心设计

> "Keep the photograph faithful; derive the lower abstract panel **only from the photograph's observed spatial, tonal, and color relationships**." 且 "Prefer relationships over silhouettes and preserve only the minimum recognition cues needed for distinctive subjects." 底板纪律："flat, continuous, and neutral ivory; exclude gradients, paper texture, grain, glow, shadows, vignettes."

（来源：vendor/ZzzLc0405__photo-abstract-editorial/SKILL.md）

## I (Interpretation) — 方法论骨架

**核心原则**：不是缩略图、不是描摹、不是风格转移——是**关系的重建**。偏好关系而非轮廓；只为独特主体的可辨认性保留最低限度识别线索。

**七步工作流**：
1. 内部审读照片 → 识别 3-6 个决定性空间事实
2. 照片作上方/主区域：只允许等比缩放或构图所需的轻微裁切
3. 将保留关系重建为稀疏抽象图案（非插画/图标/矢量）
4. 构建竖向作品：无纹理均匀象牙底板，照片/面板比例依照片调适而非机械对半，两段直接相接无框无影无拼贴胶带效果
5. 一种主标记族 + 不超过两种辅助族；调色板完全取自照片；大量留白；禁自创装饰色/符号/对称
6. 基于可见事实创作 2-5 词原创英文标题，克制的编辑衬线体置于抽象面板上
7. 仅返回完成构图，不加解说/标签/日期/logo/水印

## A1 (Past Application) — 源项目的典型应用

### 案例: 寺庙中轴线照片的关系提取
- **输入**: 一张对称构图的寺庙山门照片。
- **做法**: 提取四个决定性事实（中轴垂直线/门洞的暗-亮重叠/两侧古树的间隔节奏/屋檐的暖灰色彩角色）；以一根锥形竖块承载轴线、两个错位矩形承载明暗重叠、一列短竖线承载树距节奏、一块源自屋檐的暖灰色面收尾；标题定稿 "Axis & Shadow"。
- **结果**: 抽象面板无一笔描摹却让人认出"那道中轴线"——识别线索恰好停在可辨认的最低限度。

## A2 (Future Trigger) ★ 触发场景

### 用户会在什么情境下需要
1. 抽象双联画："把这张照片做成上真照片下抽象面板的双联画。"
2. 视觉记忆档案："给这个地点做一张极简档案海报，只要它的骨架关系。"
3. 空间构成研究：建筑/设计从业者想看一张照片的空间语法被剥离成基本关系。

### 语言信号
- "抽象编辑双联画 / diptych"
- "视觉记忆面板 / 记忆的骨架"
- "极简档案海报 / minimal archival"

### 与同 agent 兄弟 skill 的区分（互设诱饵）
- 与 photo-relic-editorial：本 skill 的抽象来源是**空间关系重建**且底板为无纹理均匀象牙色，对方是暖纸上的**墨迹压缩记忆**（一种主形态+支撑标记）；强调空间构成选这里，强调情感温度选那里。人物表现也不同：不规则短竖线 vs 短竖刻度标记。
- 与 gathered-scenes-zine：对方有版画/剪纸插画语言与撕纸边；本 skill 无插画语法、无纹理、无撕边。
- 与 minimal-zine-poster：对方从语义主题造隐喻、焦点事件占 8-25%；本 skill 必须以照片空间事实为唯一内容源。

## E (Execution) — 可执行步骤

1. **内部审读** — 从十一个维度（主体关系/尺度/轴线/方向/间隔/重叠/深度/节奏/光线/色彩角色/负空间）中锁定 3-6 个决定性事实。完成标准: 每个事实都能指认到照片中的具体可见证据。
2. **划定照片区** — 照片作上方或主区域，仅允许等比缩放/轻裁切；比例按照片特征调适不机械对半。完成标准: 明确声明未做任何重绘/延伸/滤镜级改动。
3. **重建抽象面板** — 把保留的关系译成稀疏图案；人物=不规则连续短竖线或轻锥形块面（绝不画头四肢脸服装）；地标建筑≤1-3 个身份线索、省略表面细节。完成标准: 每个标记可溯源；无缩略图化/描摹/矢量图标感。
4. **底板与标记族纪律** — 均匀象牙底板（禁渐变/纸纹/颗粒/辉光/阴影/晕影）；一主标记族 ≤两辅助族；调色板全部取自照片。完成标准: 族计数合规且色值均有照片出处。
5. **标题创作** — 基于可见事实写 2-5 词原创英文标题，克制编辑衬线体只放在抽象面板；仅在增义时加短副题。完成标准: 标题无凭空引申且排版位置正确。
6. **终检交付** — 对照 guardrails 全查后仅返回完成构图本身。完成标准: 无解说/分析/标签/日期/logo/水印混入输出。

## B (Boundary) — 边界

### 不适用场景（≥2条）
- **把照片重画成插画风/水彩风/任何风格转移** → 拒绝：风格转移正是本 skill 明文排除项，关系重建≠换画法。
- 需要情感叙事墨迹遗存的场景 → 走 photo-relic-editorial；需要大面积插画场域 → 走 gathered-scenes-zine。
- 数据可视化与信息图 → 不属视觉转译范畴。

### 已知局限 / 失效模式（≥1条）
- 最易失败在"抽象度失准"：过弱则沦为描摹或缩略图，过强则主体不可辨认——靠"最低识别线索"原则校准；模型也可能擅自给底板加纸纹或给面板添装饰图形，须逐项拦截。

### 结构红线
- 每个抽象标记必须能回答"它对应照片里哪个可见事实"；答不上来的装饰元素一律删除——宁可空，不可编。
