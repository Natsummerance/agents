# Gathered Scenes Zine — 实景拼贴海报

## R (Reading) — 核心方法

签名公式："真景为锚、插画成场、色彩成结构、撕纸成界、纸面会呼吸"

## I (Interpretation) — 决策优先级

1. 保留场景的身份和关键空间关系
2. 保持摄影部分真实性
3. 将复杂有机/重复细节压缩为少数大型可读块面
4. 插画成为大型设计场域而非字面复制
5. 摄影、插画和高饱和色相共享同一构图骨架
6. 高饱和色相改变平衡、运动、图地关系或含义
7. 在放大插画内部和周围保留充足的安静空间
8. 保持手撕纤维纸边缘的触感过渡
9. 添加一个克制的微文本元素不削弱层级

## A (Application) — Scene Card 构建

审读照片时构建内部 Scene Card：
- **核心主体**：使场景可辨认的 1-2 个元素
- **支撑元素**：建立地点或氛围的 2-3 个元素
- **色彩骨架**：主导色 + 可提取的高饱和信号色
- **光影方向**：最强的光源和阴影方向

## B (Boundary) — 边界

- ✅ 做：实景照片 → 拾景拼贴海报
- ❌ 不做：篡改照片 / 数据可视化 / UI 设计
