# Photo Relic Editorial — 照片遗存版画

## R (Reading) — 核心方法

将照片转化为上下双段构图：上方保留真实摄影，下方创建"遗存"——不是插画或装饰，而是照片的压缩视觉记忆：几笔精确标记保留主体的身份、光线、重量和情感温度。

签名特征：
- 暖象牙色/暖白色底板作为遗存区域
- 遗存使用深蓝/墨黑/灰绿/石灰 + 一个暖色信号
- 一种主要形态 + 少量支撑标记，不填满画面
- 标题小而诗意，标签式排版

## I (Interpretation) — 方法论骨架

**核心思想**：时间将照片压入暖纸上的几笔墨迹。

**五步工作流**：
1. 审读照片 → 提取 3-5 个源线索
2. 选择遗存配方（布局节奏 × 遗存语法 × 标记重量 × 标题模式）
3. 编译图像生成 prompt
4. 生成一张完成的竖向作品
5. 通过质量门检查

## A (Application) — 构图模式

| 模式 | 适用 | 特征 |
|------|------|------|
| Paper Relic | 干净简洁的场景 | 象牙底板 + 中小型遗存 + 大量留白 |
| Light-Pressed Relic | 有强烈光影的照片 | 从照片提取的冷/暖光场 + 墨迹形状 |
| Architectural Seal | 建筑/城市天际线 | 简化为块面/弧线/基线 + 暖色信号 |
| Horizon Memory | 城市/水面/道路 | 水平锚定线防止形态漂浮 |
| Human Scale Echo | 有人物的场景 | 人物为短竖刻度标记 |

## B (Boundary) — 边界

- ✅ 做：真实照片 → 编辑艺术作品
- ❌ 不做：篡改照片内容 / 凭空虚构摄影 / 数据可视化

**质量红线**：照片区域不可被重绘、美化或加滤镜。
