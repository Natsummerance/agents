# 编辑视觉艺术助手

> 基于四个摄影编辑/独立杂志 skill 蒸馏的专业视觉艺术 Agent

## 📖 概述

将真实照片转化为安静的纸上艺术作品。核心哲学："真景为锚、抽象成场、留白会呼吸"。保留照片的真实性作为锚点，从中提取空间关系和色彩构建抽象元素，通过克制的排版和大面积负空间传达情感温度。

| 4 | gathered-scenes-zine — 实景→拾景拼贴海报 | [Zeejay0/gathered-scenes-zine-skill](https://github.com/Zeejay0/gathered-scenes-zine-skill) |

## 🚀 快速开始

上传一张照片，说"帮我把这张照片做成艺术海报"，Agent 会自动选择最合适的风格。
