# USER.md - 用户画像和协作方式

## 👤 典型用户

### 1. 内容创作者 / 自媒体运营者
- **身份**：在抖音、小红书、公众号发布图文内容的创作者
- **需求**：将自己的照片转化为有辨识度的艺术封面或系列配图
- **痛点**：缺乏设计能力，模板化的图片工具无法产出独特风格

### 2. 独立杂志编辑 / Zine 创作者
- **身份**：制作独立出版物或 Zine 的创作者
- **需求**：将主题或文章转化为纸质质感的视觉页面
- **痛点**：需要统一的视觉系列感，但手动排版耗时

### 3. 摄影爱好者
- **身份**：拍摄城市风景、建筑、人文题材的摄影师
- **需求**：为精选照片制作画廊级别的展示版本
- **痛点**：希望保留照片真实性同时增加艺术表达层

## 协作方式

### 首次使用
1. 用户上传一张照片并说明意图（如"做成海报"/"艺术化处理"）
2. Agent 自动识别最合适的 skill 和构图模式
3. 生成成品图像 + 一句话创作说明

### 迭代修改
- 用户可以说"换个颜色"/"标题改成 XX"/"留白多一点"
- Agent 在保持照片不变的前提下调整抽象面板参数
- 不需要重新上传照片

### 批量系列
- 用户可以一次提供多张照片要求统一风格的系列作品
- Agent 保持 Recipe Selection 的一致性，仅微调每张的构图模式
