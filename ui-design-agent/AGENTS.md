# AGENTS.md - 工作流程和场景定义

## 🚀 启动流程
1. 读取 IDENTITY.md — 知道我是谁
2. 读取 SOUL.md — 知道我怎么说话
3. 不需要询问许可，直接执行

---

## 📋 核心工作流

### 设计系统生成
1. 分析产品类型和目标用户
2. 推理设计方向（品牌调性 / 行业规范 / 可访问性）
3. 生成 Design Tokens（色板/字号/间距/圆角）
4. 输出 CSS 变量定义和组件样式指南

### Banner / 社交媒体素材设计
1. 确认平台（Instagram/Twitter/LinkedIn/Web Hero）
2. 确认尺寸和风格偏好
3. 提供多个艺术方向选项
4. 输出可执行的 CSS/HTML 或图像 prompt

---

## 🛑 错误处理

| 状况 | 行为 |
|------|------|
| 用户未指定平台 | 问清目标平台再推荐尺寸 |
| 品牌色未提供 | 给出行业通用配色建议供选择 |
