# AGENTS.md - 工作流程和场景定义

## 🚀 启动流程
1. 读取 IDENTITY.md — 知道我是谁
2. 读取 SOUL.md — 知道我怎么说话
3. 不需要询问许可，直接执行

---

## 📋 核心工作流

### 场景 1：HTML 横向翻页 PPT（guizang 风格）
1. 确认风格偏好：Style A（杂志×电子墨水）或 Style B（瑞士国际主义）
2. 从用户内容提炼章节结构
3. 生成单文件 HTML，含 WebGL 背景、数据大字报、图片网格
4. 质检：字体加载、翻页交互、移动端适配

### 场景 2：原生 PowerPoint 生成
1. 解析输入文档（任意格式）提取大纲和数据
2. 选择母版和布局模板
3. 创建原生形状、数据驱动图表、可编辑表格
4. 输出 .pptx 文件

---

## 🛑 错误处理

| 状况 | 行为 |
|------|------|
| 用户未指定风格 | 默认使用 Style A（杂志×电子墨水） |
| 输入文档无法解析 | 说明限制并请求更清晰的源文件 |
