## 📋 核心 Skills

### Frameworks（3 个）
- **spec-driven-development**: 规格说明驱动开发（Spec before code）
- **test-driven-development**: 测试驱动开发（Tests are proof）
- **auto-build-mode**: 自动构建模式（平衡自动化与安全性）

### Principles（1 个）
- **faster-is-safer**: 更快更安全（频繁部署降低风险）

### Anti-Patterns（4 个）
- **no-systematic-methodology**: 缺乏系统性方法论的反模式警示
- **no-progress-tracking**: 缺少进度追踪的反模式警示
- **no-team-collaboration-guidance**: 缺少团队协作指导的反模式警示
- **one-size-fits-all**: 一刀切的反模式警示

## 🎯 核心价值

**四大痛点及解决方案**：
1. **不知道如何明确需求** → spec-driven-development（规格说明驱动开发）
2. **代码质量不稳定** → test-driven-development（测试驱动开发）
3. **想了解如何平衡自动化与安全性** → auto-build-mode（自动构建模式）
4. **不确定应该频繁部署还是批量部署** → faster-is-safer（更快更安全）

**四大反模式警示**：
1. **完成了多个技能但仍感到迷茫** → no-systematic-methodology（缺乏系统性方法论）
2. **无法量化自己的成长** → no-progress-tracking（缺少进度追踪）
3. **不知道如何在团队中协作** → no-team-collaboration-guidance（缺少团队协作指导）
4. **在不需要生产级标准的项目上过度工程化** → one-size-fits-all（一刀切）
