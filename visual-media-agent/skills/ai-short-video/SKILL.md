# AI 短视频全自动生产管线

## R (Reading) — 源项目核心设计

> "只需提供视频**主题**或**关键词**，即可自动生成视频脚本、匹配素材、生成字幕和背景音乐，并合成高清短视频。"
>
> — 上游 README.md（harry0703/MoneyPrinterTurbo）

上游核心纪律：管线各环节可独立替换但顺序不可颠倒——脚本先行（LLM 同时产出文案与素材搜索关键词），素材来源三选一（Pexels/Pixabay/Coverr 免费图库、本地上传、WaveSpeed AI 文生视频兜底）；Agent 运行模式下只向用户索要一次缺失凭据，全程不回显任何 API Key，成功以 `MPT_RESULT` + 实际存在的非空文件为准，不做多余轮询。

## I (Interpretation) — 方法论骨架

1. **主题即输入，成片即输出**：用户给主题/关键词/现成脚本三者之一即可启动；交付物是可直接发布的 MP4 文件路径，不是操作教程。
2. **五段流水线**：脚本(含关键词提炼) → 素材匹配 → TTS 配音 → 字幕 → 合成；每段都有可替换 Provider（LLM 十余家、TTS 八家、字幕 edge/whisper 双模式），默认组合全免费（Edge TTS + edge 时间戳字幕）。
3. **画幅先于内容**：竖屏 9:16 `1080x1920` 或横屏 16:9 `1920x1080` 必须在生成前确定；批量生成多个候选再择优是上游推荐的质量策略。
4. **凭据最小化交互**：缺失的 LLM key / Pexels key 一次性合并索取；exit code 10=要凭据、0=交付、1=按日志修复重试一次——不把环境问题伪装成生成失败。

## A1 (Past Application) — 源项目典型应用

### 案例: 科普主题竖屏成片
- **输入**: 主题「为什么我们仍要探索太空」，未提供任何素材
- **做法**: LLM 写中文脚本并提炼关键词 → Pexels 匹配太空素材 → Edge TTS 中文女声 → edge 字幕 → 随机 BGM → 9:16 合成
- **结果**: 27 秒竖屏成片，含配音/字幕/背景音乐，直接可发布

### 案例: 自定义脚本口播视频
- **输入**: 用户自己写好的带货文案一段
- **做法**: 跳过脚本生成环节，文案直入 TTS；素材走本地上传避免图库错配
- **结果**: 口播节奏由用户文案控制，画面与卖点逐句对应

### 案例: 同主题双画幅批量产出
- **输入**: 一份科普脚本，要同时投竖屏短视频与横屏中长视频位
- **做法**: 以不同画幅参数各跑一轮生成，产出多个候选后择优交付
- **结果**: 9:16 与 16:9 各一条成片，素材复用、配音独立

## A2 (Future Trigger) ★ 触发场景

### 用户会在什么情境下需要
1. 「给我做个短视频」——只有主题没有素材，希望从零到成片一条龙
2. 有现成文案/脚本，缺配音、字幕、画面合成的自动化装配
3. 要批量产出多平台尺寸版本（竖屏抖音 + 横屏 B 站）并择优发布

### 语言信号

- "帮我用 AI 生成一条带配音和字幕的短视频"
- "把这个主题做成视频，竖屏的发抖音"
- "我写好了文案，帮我配上画面和音乐出成片"

### 与相邻 skill 的区分

- 与 `gpt-image-prompting` 的区别: 本 skill 产出**动态成片 MP4**（脚本→配音→字幕→合成全管线）；后者产出**静态图像的结构化 prompt**（生图前的提示词工程）。用户只要"一张图的提示词"→ 转 gpt-image-prompting。

## E (Execution) — 可执行步骤

1. **需求确认与合规预检** — 完成标准: 主题/受众/目标平台/画幅(9:16 或 16:9)/时长确定，且用户知晓成片发布需添加 AIGC 内容标识（见 B 段红线）
2. **凭据一次性盘点** — 完成标准: 缺失的 LLM key、素材源 key 等必需项合并为一次请求索取；对话中绝不回显任何密钥或含密钥的配置片段
3. **脚本生成** — 完成标准: 脚本文案定稿（自定义脚本则校验后直通），同时产出逐句素材搜索关键词
4. **素材获取** — 完成标准: 每个关键词至少 1 条可用素材命中免费图库，或明确切换 WaveSpeed 文生视频兜底并向用户说明成本差异
5. **配音与字幕对齐** — 完成标准: TTS 音色确认（默认 Edge TTS 免费档）；字幕时间轴与语音逐句对齐（edge 时间戳或 whisper 转写二选一并说明取舍）
6. **合成与交付** — 成标准: 返回实际存在且非空的 MP4 绝对路径，画幅/时长符合约定；附 AIGC 标识提醒与所用音乐的版权状态说明
7. **可选自动发布** — 完成标准: 仅当用户已配置 Upload-Post 并确认目标平台与可见性后才执行上传，否则止步于交付文件

## B (Boundary) — 边界

### 不适用场景
- 只要"一张图/一张海报的提示词"而非视频 → `gpt-image-prompting`
- 真人实拍素材的专业剪辑调色包装（非线性编辑软件的工作流）
- 强分镜设计的动画短片/广告片（本管线是素材装配逻辑，不是导演逻辑）
- 直播推流、实时互动视频等流媒体场景（本管线产出离线成片文件）

### 已知局限 / 失败模式
- 图库素材靠语义检索匹配，抽象/本土化主题易错配；文生视频兜底产生额外费用
- Edge TTS 自然度有限；whisper 字幕首次需下载约 3GB 模型；ffmpeg 自动下载失败时须手动配置路径
- 上游自带背景音乐来自 YouTube 视频（README 自述"如有侵权请删除"），商用前必须替换
- 命令行参数优先级为 显式参数 > WebUI 保存值 > 内置默认值，自备音频路径不被保存、必须显式传入

### 合规红线（必须执行）
- **AIGC 内容标识义务**：依据《人工智能生成合成内容标识办法》，AI 生成的音视频对外发布必须添加显式标识（平台自主声明入口 + 元数据隐式标识）；交付成片时主动提醒，拒绝"去掉 AI 痕迹以便伪装真人原创"类请求
- **素材/音乐版权核查**：仅使用 Pexels/Pixabay/Coverr 等明确许可的素材与其允许的用途；影视解说/搬运剪辑涉及信息网络传播权，未获授权不得协助
- **平台规则**：批量同质化内容触发限流与原创判定，不为"铺量养号"式需求批量灌产；发布前建议人工过审内容质量
