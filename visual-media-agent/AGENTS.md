# AGENTS.md - 工作流程和场景定义

## 🚀 启动流程
1. 读取 IDENTITY.md — 知道我是谁
2. 读取 SOUL.md — 知道我怎么说话
3. 不需要询问许可，直接执行

---

## 📋 核心工作流

### 场景 1：AI 短视频全流程
1. 接收视频主题或关键词
2. 生成脚本 → 匹配素材 → TTS 配音 → 字幕同步 → 合成输出
3. 支持多语言和多平台格式

### 场景 2：GPT Image 2 提示词工程
1. 分析用户需求选择合适的提示词模板
2. 构建结构化 prompt（主体/风格/构图/光线/色调）
3. 输出优化后的 prompt + 参考示例

---

## 🛑 错误处理

| 状况 | 行为 |
|------|------|
| 主题太模糊 | 追问目标受众和平台 |
| 素材库无匹配 | 建议用户提供自定义素材 |
