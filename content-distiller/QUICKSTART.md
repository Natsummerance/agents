# Content Distiller 快速开始指南

## 🚀 5 分钟上手

### 第 1 步：准备内容文本
选择一份高价值内容（书籍、视频转写、播客文字稿等），确保你有完整的文本文件。

### 第 2 步：启动蒸馏
```
用户: 帮我拆《书名》
Agent: 请提供文本文件路径
用户: /path/to/book.txt
```

### 第 3 步：确认骨架（阶段 0）
```
Agent: 已完成 BOOK_OVERVIEW.md
骨架我理解对了吗？
用户: 理解正确，继续
```

### 第 4 步：确认入选名单（阶段 1.5）
```
Agent: 三重验证完成，通过 12 个候选
这 12 个会做成 skill，有想调整的吗？
用户: 没问题，开始生成
```

### 第 5 步：安装 skills（阶段 5）
```
Agent: 已完成！请问你想把 skills 安装到哪里？
1. 用户级: ~/.openclaw/skills/<book-slug>/
2. 项目级: .openclaw/skills/<book-slug>/
用户: 安装到用户级
```

### 第 6 步：使用 skills
在对话中自然提及触发场景，skills 会自动激活。

## ⚡ 快速命令

- **蒸馏单本书**: `帮我拆《书名》`
- **蒸馏视频**: `把这个视频蒸馏成 skill: <URL>`
- **批量蒸馏**: `我想批量蒸馏这 N 本书`
- **继续中断的任务**: `继续昨天的《书名》蒸馏`

## 🆘 常见问题

**Q: 没有文本文件怎么办？**  
A: 必须提供源文本。如果是视频/播客，先用 video-downloader 提取转写文本。

**Q: 可以蒸馏英文内容吗？**  
A: 可以，原文引用限制为 ≤100 词/段。

**Q: 蒸馏需要多长时间？**  
A: 取决于内容长度和复杂度，通常 30 分钟 - 2 小时。

**Q: 可以中途停止吗？**  
A: 可以，支持断点续跑。下次继续时会从上次中断的阶段恢复。
