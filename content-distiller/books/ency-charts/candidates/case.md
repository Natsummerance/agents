# Case Candidates

## C1: KPI 指标卡片组设计案例

**原文引用**：
> "Prompt 1: 生成 KPI 指标卡片组... 使用 Grid 布局，卡片包含：label (12px/#86909C), value (28px/600), trend indicator (11px, up=#00B42A, down=#F53F3F)。支持响应式：XL 6列 / L 4列 / M 3列 / S 2列 / XS 1列。每个卡片可选嵌入 40px 高的 Micro Chart。"（来自 9. Agent Prompt Guide）

**案例描述**：
这是一个**典型的 Dashboard 顶部概览区域设计**，通过 KPI 指标卡快速呈现关键业务数据，并辅以趋势标识和微型图表提供上下文。

**关键设计要素**：
1. **信息层级**：Label（指标名）→ Value（主数值）→ Trend（同比/环比）
2. **视觉强调**：Value 使用 28px/600 字重 + DIN Alternate 数字字体，确保第一眼可见
3. **趋势可视化**：用颜色（绿/红）+ 箭头图标直观展示增减
4. **可选微型图表**：在卡片底部嵌入 40px 高的迷你折线图，展示近期趋势
5. **响应式适配**：从 XL 的 6 列到 XS 的 1 列自动重排

**价值体现**：
- 快速洞察：用户一眼看到核心指标
- 趋势感知：通过颜色和箭头立即判断好坏
- 空间高效：单卡片承载 3 层信息（当前值/趋势/历史）

**source_chapter**: 4.2 KPI Card + 9. Agent Prompt Guide - Prompt 1

## C2: 多系列柱状图设计案例

**原文引用**：
> "Prompt 2: 生成多系列柱状图... 使用品牌分类色板 (从 #2469FF 开始)，barWidth: 60%，圆角 4px。Y 轴分割线使用虚线 #F2F3F5，X 轴标签 11px/#86909C。Tooltip 使用暗底样式 rgba(29,33,41,0.92)，Legend 置于底部。数据点数量 ≥ 10 时添加 dataZoom 组件。"（来自 9. Agent Prompt Guide）

**案例描述**：
这是一个**对比多个类别在多个维度上的表现**的典型场景，如"各产品线在不同季度的销售额对比"。

**关键设计要素**：
1. **色彩分配**：每个系列使用品牌分类色板中的一个颜色（按序分配）
2. **柱子样式**：barWidth 60% + 圆角 4px，既清晰又柔和
3. **网格优化**：仅 Y 轴使用虚线分割线，X 轴无网格线（减少视觉噪音）
4. **交互增强**：Tooltip 暗底白字提升可读性，Legend 置于底部避免遮挡图表
5. **大数据处理**：≥10 个数据点时自动添加 dataZoom 组件，支持缩放查看

**价值体现**：
- 多维对比：同时展示类别×维度的交叉数据
- 可扩展性：dataZoom 支持大量数据点的浏览
- 视觉克制：仅必要的网格线，避免干扰数据读取

**source_chapter**: 4.6 图表类型样式速查表 + 9. Agent Prompt Guide - Prompt 2

## C3: 仪表盘概览页面设计案例

**原文引用**：
> "Prompt 3: 生成仪表盘概览页面... 布局：顶行 KPI 卡片 (4个) + 中行 图表卡片 (2列，折线图+柱状图) + 底行 微型图表卡片组 (4个)。使用 CSS Grid + chart-card 组件样式，卡片间距 16px。支持响应式重排：M 断点以下转为 2 列或 1 列。"（来自 9. Agent Prompt Guide）

**案例描述**：
这是一个**完整的 Dashboard 页面布局案例**，通过三层结构（KPI → 详细图表 → 微型趋势）实现从宏观到微观的信息递进。

**关键设计要素**：
1. **信息分层**：
   - 顶层：KPI 指标卡（4 个）— 核心数据快照
   - 中层：标准图表（2 列）— 详细趋势分析
   - 底层：微型图表（4 个）— 辅助指标的简化展示
2. **统一容器**：所有图表包裹在 .chart-card 中，保持视觉一致性
3. **响应式重排**：M 断点以下自动从 2 列变为 1 列，确保移动端可读性

**价值体现**：
- 信息架构清晰：从宏观到微观的自然浏览路径
- 空间利用高效：三层布局充分利用垂直空间
- 响应式友好：自动适配不同屏幕尺寸

**source_chapter**: 5. Layout Principles + 9. Agent Prompt Guide - Prompt 3

## C4: 饼图/环形图设计案例

**原文引用**：
> "Prompt 4: 生成饼图/环形图... 内半径 50%，外半径 70%，扇区不超过 6 个。使用品牌分类色板前 N 个颜色。中心显示总数值 (20px/600)。Legend 置于右侧，每项包含名称 + 百分比。Tooltip 显示名称、数值、占比百分比。如果数据项 > 6，自动合并尾部为'其他'。"（来自 9. Agent Prompt Guide）

**案例描述**：
这是一个**展示部分与整体关系**的经典场景，如"市场份额分布"或"预算分配比例"。

**关键设计要素**：
1. **环形设计**：内半径 50% + 外半径 70%，中心留白用于显示总数值
2. **扇区限制**：最多 6 个扇区，超过时自动合并尾部为"其他"（避免碎片化）
3. **中心强调**：总数值使用 20px/600 字重，成为视觉焦点
4. **完整上下文**：Legend 显示名称+百分比，Tooltip 显示名称+数值+占比

**价值体现**：
- 比例直观：环形图比饼图更易比较扇区大小
- 信息完整：中心总值 + 扇区占比 + Tooltip 详细数据
- 防滥用机制：自动合并小扇区，避免视觉混乱

**source_chapter**: 4.6 图表类型样式速查表 + 9. Agent Prompt Guide - Prompt 4

## C5: 时序折线面积图设计案例

**原文引用**：
> "Prompt 5: 生成时序折线面积图... 线宽 2px，symbol: circle 6px，面积填充透明度 0.15→0.02 渐变。数据点 > 10 时自动隐藏 symbol 显示。X 轴为时间轴 (11px/#86909C)，Y 轴分割线虚线。Tooltip 使用 cross 触发模式。"（来自 9. Agent Prompt Guide）

**案例描述**：
这是一个**展示时间序列数据趋势**的场景，如"近 30 天的日活跃用户数变化"。

**关键设计要素**：
1. **双重编码**：折线（精确值）+ 面积填充（趋势感知）
2. **智能简化**：数据点 >10 时隐藏 symbol，避免视觉拥挤
3. **渐变填充**：opacity 从 0.15 到 0.02 的线性渐变，营造"呼吸感"
4. **Cross Tooltip**：十字交叉线帮助用户精确定位时间和数值

**价值体现**：
- 趋势清晰：面积填充强化趋势感知
- 细节可控：symbol 的智能显示平衡精度与清晰度
- 交互友好：cross 模式便于精确读取数据

**source_chapter**: 4.6 图表类型样式速查表 + 9. Agent Prompt Guide - Prompt 5
