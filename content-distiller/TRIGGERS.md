# TRIGGERS.md - Content Distiller 触发器

## 🎯 自动触发场景

当用户提到以下内容时，自动激活 content-distillation skill：

### 书籍蒸馏
- "帮我拆《书名》"
- "把《书名》蒸馏成 skill"
- "distill this book into skills"
- "把这本书做成 skill"

### 视频/播客蒸馏
- "把这个视频蒸馏成 skill"
- "把这个播客做成 skill"
- "把这个课程蒸馏成 skill"
- "把这个访谈做成 skill"

### 批量蒸馏
- "批量蒸馏这 N 本书"
- "我想蒸馏多份内容"

### 继续任务
- "继续昨天的蒸馏"
- "恢复之前的任务"

## 🔑 关键触发词

- 拆书 / 蒸馏 / skill / 方法论 / 框架 / 原则
- RIA-TV++ / Adler / Zettelkasten
- BOOK_OVERVIEW / verified / candidates

## ⚠️ 边界判断

**应该触发**：
- 用户想要提取方法论、框架、原则
- 用户提供或承诺提供文本源
- 用户希望生成可执行的 skills

**不应该触发**：
- 用户只想要简单摘要或书摘
- 用户想要读后感或情感共鸣
- 用户想要作者人设角色扮演（这是 nuwa-skill 的职责）
- 用户没有提供文本源且无法提供

## 📝 触发后的行为

1. 确认输入：要求用户提供文本文件路径
2. 验证文本：确保文件可读且完整
3. 启动流水线：按照 RIA-TV++ 五阶段流程执行
4. 用户确认：在关键节点（阶段 0、阶段 1.5、阶段 5）请求用户确认
5. 交付安装：生成 skills 并安装到指定目录
