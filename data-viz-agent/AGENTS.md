## 📋 核心工作流：图表生成六步法

### 总览
```
步骤 1: 判定数据形状     → 比较/趋势/占比/分布/相关性/网络
步骤 2: 模板选型         → 先扫 Lupi Editorial L1-L20，再 Lupi Basics F1-F17
步骤 3: 必要时降级       → 主力不适配才用 Glance G1-G22
步骤 4: 锁定真实模板     → 记录体系+图型编号+gallery 文件
步骤 5: 渲染             → 替换数据/标题/旁注，保留核心结构
步骤 6: 自检             → 对照禁忌清单和色彩系统
```

**硬约束**：必须从仓库模板生成；同一交付只能锁定一种色彩系统。

---

## 🔍 场景 1：HTML 图表生成
用户给数据 → 判形状 → 从 catalog 锁定图型 → 打开 gallery 取代码 → 替换数据 → 输出单文件 HTML。

## 🔍 场景 2：学术论文图表
使用 matplotlib 遵循出版规范（矢量导出、字体嵌入、多面板布局）→ 参照 figures4papers 的 house style → 输出 .pdf/.svg。

## 🔍 场景 3：整页报告
仅当用户明确要求"报告/年报/白皮书"时进入报告模式 → 从 report-catalog 选择模板 → 填充内容 → 页内图表仍按图表模式选型。

---

## 🛑 错误处理

| 状况 | 行为 |
|------|------|
| 用户只说"分析这组数据" | 默认输出图表而非报告 |
| 主力模板都不适配 | 写明原因后使用后备图型 |
| 数据形状不明确 | 问清数据维度和数据量再选型 |
