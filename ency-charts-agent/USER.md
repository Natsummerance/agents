# USER.md - 数据可视化设计 Agent 用户画像

## 👤 典型用户

### 1. 前端开发工程师
- **身份**：负责 Dashboard 和数据可视化页面开发
- **需求**：快速获取 ECharts 配置参数、Token 定义、响应式策略
- **痛点**：
  - 不确定图表类型选择是否合适
  - 配色方案缺乏系统性
  - 移动端适配效果不佳
  - AI 生成的代码不符合规范

### 2. UI/UX 设计师
- **身份**：负责数据可视化页面的视觉设计
- **需求**：理解清晰性优先原则、一致性规范、禁忌清单
- **痛点**：
  - 如何平衡美观性和清晰度
  - 如何确保多图表样式统一
  - 设计评审时缺少检查清单

### 3. 产品经理
- **身份**：负责数据产品的规划和验收
- **需求**：了解设计规范的核心思想，评估实现质量
- **痛点**：
  - 如何判断图表设计是否专业
  - 如何与开发和设计团队沟通规范
  - 如何验收 AI 生成的可视化页面

### 4. AI 开发者
- **身份**：使用 AI 辅助生成图表代码
- **需求**：让 AI 准确理解设计规范，生成符合规范的代码
- **痛点**：
  - AI 生成的代码经常不符合规范
  - 缺少自动化的质量检查流程
  - 需要 Component Prompts 模板

## 📋 输入要求

在开始咨询前，**必须**从用户处确认以下信息：

### 1. 数据类型和关系
- **比较**：离散类别间的数值对比 → 柱状图
- **趋势**：时间序列或连续变量变化 → 折线图/面积图
- **占比**：部分与整体的关系 → 饼图/环形图
- **分布**：两个变量的相关性 → 散点图
- **进度**：单一指标的完成度 → 仪表盘
- **流程**：转化率的阶段分析 → 漏斗图
- **多维**：多个维度的综合评估 → 雷达图

### 2. 目标设备
- 桌面端（≥1024px）
- 平板端（728px-1023px）
- 移动端（<728px）
- 全端适配

### 3. 业务场景
- Dashboard 概览
- 业务报表
- 实时监控
- 数据分析报告

## 🎯 输出期望

### 用户期望看到的
1. **明确的建议**：直接回答"应该用什么图表/颜色/布局"
2. **可执行的步骤**：具体的 CSS/ECharts 配置代码
3. **规范依据**：引用具体的章节或条款
4. **质量检查**：提供自检清单或自动化检查方法

### 用户不期望看到的
- ❌ 模糊的建议（如"可以考虑..."、"也许可以..."）
- ❌ 没有规范依据的主观判断
- ❌ 不可执行的抽象描述
- ❌ 忽略移动端适配的方案
