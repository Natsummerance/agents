# ENCY-charts 数据可视化设计规范 · 精华 distilled

> 基于《ENCY-charts 数据可视化设计规范》蒸馏的核心方法论，面向设计者、开发者和 AI 代理的实战指南。

---

## 🎯 核心思想

ENCY-charts 不是一套简单的图表样式规范，而是一个**完整的数据可视化设计系统**，涵盖从基础 Token 架构到 AI 友好规范的五个层面：

1. **设计哲学**：清晰性优先，克制装饰，服务于数据洞察
2. **视觉系统**：三层 Token 架构（Seed → Component → Semantic），确保一致性
3. **图表规范**：8 种常见图表类型的选择决策框架和样式参数
4. **响应式策略**：5 断点适配，移动端特殊优化
5. **AI 友好化**：Quick Reference + Component Prompts + Iteration Guide 三件套

---

## 📐 第一层：设计哲学 — 清晰性优先

### 五条子原则

1. **最高对比度**：数据与背景对比度 ≥4.5:1（WCAG AA 标准）
2. **数据层级分明**：通过字体大小/字重/颜色区分主数据和辅助信息（仅用 2 种字重：600/400）
3. **克制装饰**：纯扁平化设计，无 3D 效果/渐变填充/毛玻璃
4. **可读性第一**：轴标签最小 11px，KPI 数值使用 DIN Alternate 等宽字体 + tabular-nums
5. **合理留白**：基准间距 16px，区块间距 24px，避免视觉压迫

### 关键洞察

> "数据图表是业务决策的关键工具，设计需服务于数据本身，避免过度装饰干扰数据读取。"

## 🎨 第二层：视觉系统 — 三层 Token 架构

### Seed Token（种子层）
最基础的原子值，不可再分解：
```css
--seed-brand: #4B7AFA;           /* 品牌主色 */
--chart-font-family: "PingFang SC", ...;  /* 字体族 */
--chart-gap: 16px;               /* 基准间距 */
```

### Component Token（组件层）
基于 Seed 组合成的组件样式：
```css
--chart-card-bg: #FFFFFF;        /* 卡片背景 */
--chart-grid-line: #F2F3F5;      /* 网格线 */
--chart-tooltip-bg: rgba(29,33,41,0.92);  /* Tooltip 背景 */
```

### Semantic Token（语义层）
赋予业务含义的颜色：
```css
--chart-success: #00B42A;        /* 成功/上涨 */
--chart-warning: #FF7D00;        /* 警告 */
--chart-danger: #F53F3F;         /* 危险/下跌 */
--chart-info: #2469FF;           /* 信息/中性 */
```

### 核心价值

- **一致性**：所有组件共享同一套 Token
- **可维护性**：修改 Seed Token 即可全局更新
- **主题切换**：通过 `[data-theme="dark"]` 覆盖 Token 实现暗色模式

## 📊 第三层：图表规范 — 8 种图表类型选择决策框架

### 决策流程

1. **识别数据关系**：比较/趋势/占比/分布/进度/流程/多维
2. **检查数据量约束**：饼图扇区 ≤6 个，折线图数据点 ≥10 时隐藏 symbol
3. **应用关键约束**：柱状图 Y 轴从 0 开始，禁用 3D 效果
4. **选择图表类型**：根据匹配结果选择对应图表
5. **应用样式规范**：使用对应的 barWidth/lineWidth/radius 等参数

### 8 种图表类型速查

| 图表类型 | 适用场景 | 关键样式参数 |
|---------|---------|-------------|
| 柱状图 | 离散类别对比 | barWidth: 60%, borderRadius: [4,4,0,0] |
| 折线图 | 时间序列趋势 | lineWidth: 2px, symbolSize: 6 (≥10 点时隐藏) |
| 饼图 | 占比展示 | radius: ['50%','70%'], 扇区 ≤6 个 |
| 面积图 | 趋势+总量感知 | lineWidth: 0, 渐变 fill opacity: [0.15,0.02] |
| 散点图 | 两个变量的相关性 | symbolSize: 8, 透明度 0.6 |
| 仪表盘 | 单一指标的完成度 | progress: { width: 8 } |
| 雷达图 | 多个维度的综合评估 | lineWidth: 1.5, 填充 opacity: 0.1 |
| 漏斗图 | 转化率的阶段分析 | gap: 2px, 标签右对齐 |

### 四大禁忌（Don'ts）

1. **3D 饼图陷阱**：扭曲数据比例感知，必须禁用
2. **Y 轴不从零**：放大微小差异，导致用户错误判断
3. **相似色混淆**：相邻颜色相似度 >80%，色盲用户无法区分
4. **Tooltip 省略单位**：造成量级歧义

## 📱 第四层：响应式策略 — 5 断点适配

### 断点定义

| 断点 | 宽度 | 图表格列数 | KPI 卡列数 | 图表高度 |
|-----|------|-----------|-----------|---------|
| XL | ≥1920px | 3 列 | 6 列 | 240px |
| L | ≥1440px | 3 列 | 4-5 列 | 220-240px |
| M | ≥1024px | 2 列 | 3-4 列 | 240px |
| S | ≥728px | 2 列 | 2 列 | 220px |
| XS | <728px | 1 列 | 1 列 | 200px |

### 移动端特殊优化

- **柱状图转为水平方向**：横向排版更友好
- **Legend 移至底部**：节省顶部空间
- **Tooltip 固定于底部**：避免跟随手指遮挡数据
- **触摸目标最小 44x44px**：符合人体工程学

## 🤖 第五层：AI 友好化 — 三件套架构

### Quick Reference（快速参考）
用一句话压缩核心规则：
> "ENCY Charts: 8 分类色板, 7 级顺序色板, 3 种卡片类型 (KPI/Micro/Chart), 4 断点, 图表卡片圆角 8px/边框 #E5E6EB/阴影 xs, Tooltip 暗底白字 rgba(29,33,41,0.92), 品牌主色 #2469FF..."

### Component Prompts（组件提示词）
提供典型场景的完整 prompt 模板（共 5 个）：
- Prompt 1: 生成 KPI 指标卡片组
- Prompt 2: 生成多系列柱状图
- Prompt 3: 生成仪表盘概览页面
- Prompt 4: 生成饼图/环形图
- Prompt 5: 生成时序折线面积图

### Iteration Guide（迭代指南）
10 条必检项：
1. 颜色第一位
2. 卡片是基本单位
3. Tooltip 不离散
4. 数据为空先处理
5. 移动端先考虑
6. 动画不超过 1 秒
7. 单位不可省
8. 图例排序与数据一致
9. 暗色模式双色板
10. 可访问性必检

## 💡 如何使用

### 对于设计师
1. 阅读"设计哲学"和"视觉系统"章节，理解清晰性优先原则
2. 参考"图表规范"中的 8 种图表类型选择决策框架

### 对于开发者
1. 复制"视觉系统"中的 Token 定义到 CSS 文件
2. 参考"图表规范"中的样式参数配置 ECharts
3. 使用"AI 友好化"中的 Component Prompts 让 AI 生成符合规范的代码

1. 加载本规范对应的 19 个 skills
2. 根据用户问题触发相应的 skill
3. 使用 Iteration Guide 的 10 条检查项自检生成结果
