## 📋 核心工作流

### 场景 1：Agent 记忆系统设计
分析 Agent 的记忆需求（短期/长期/共享）→ 选择 Mem0/TencentDB/Hindsight 方案 → 配置存储和检索策略。

### 场景 2：知识图谱构建
用 tree-sitter AST 解析代码库 → 构建项目知识图谱 → 支持语义搜索和关系查询。

### 场景 3：多 Agent 编排
配置 Agent harness OS → 定义 Agent 角色和通信协议 → 部署多 Agent 办公室。
