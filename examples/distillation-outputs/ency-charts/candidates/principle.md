# Principle Candidates

## P1: 清晰性优先原则（Clarity-First Principles）

**原文引用**：
> "设计哲学: ENCY 数据可视化遵循'清晰、准确、高效'的设计原则... 视觉基调和关键词: 清晰（最高对比度，数据层级分明）、克制（色彩服务于数据意义，非装饰）、精确（轴标签、数值标签可读性第一）"（来自 1. Visual Theme & Atmosphere）

**原则清单**：
1. **最高对比度原则**：确保数据与背景、数据系列之间有足够对比度（≥4.5:1）
2. **数据层级分明原则**：通过字体大小、字重、颜色区分主数据和辅助信息
3. **克制装饰原则**：避免过度装饰干扰数据读取（纯扁平化，无拟物/毛玻璃）
4. **可读性第一原则**：轴标签、数值标签的清晰度优于美观性
5. **合理留白原则**：避免视觉压迫，给数据"呼吸"空间

**应用场景**：
- 评估现有图表是否"清晰"
- 设计新图表时的自检清单
- 与设计团队对齐视觉标准

**source_chapter**: 1. Visual Theme & Atmosphere

## P2: 一致性至上原则（Consistency Principles）

**原文引用**：
> "一致: 跨图表类型保持色彩/字体/间距统一... Do's: 始终使用品牌分类色板... Don'ts: 不要使用超过 2 种字重在图表中"（来自 1. Visual Theme + 7. Do's and Don'ts）

**原则清单**：
1. **色彩一致性原则**：所有图表使用同一套分类色板（从 --chart-c-1 开始按序使用）
2. **字体一致性原则**：图表中不使用超过 2 种字重组合（KPI 数值用 600，其余用 400）
3. **间距一致性原则**：使用统一的间距系统（--chart-spacing-xs/sm/md/lg/xl/2xl）
4. **组件样式一致性原则**：所有图表卡片使用相同的圆角/边框/阴影

**核心价值**：
- 降低用户认知成本：无需重新学习每种图表的样式
- 提升品牌识别度：统一的视觉语言强化品牌形象
- 简化开发维护：一套 Token 服务所有图表

**应用场景**：
- 多图表 Dashboard 的样式统一
- 设计系统的组件库开发
- 跨团队协作的样式对齐

**source_chapter**: 1. Visual Theme + 3. Typography Rules + 7. Do's and Don'ts

## P3: 语义化配色原则（Semantic Coloring Principles）

**原文引用**：
> "语义色: --chart-success: #00B42A, --chart-warning: #FF7D00, --chart-danger: #F53F3F, --chart-info: #2469FF... Do's: KPI 趋势向上用绿色，向下用红色"（来自 2.3 语义色 + 4.2 KPI Card）

**原则清单**：
1. **业务含义映射原则**：颜色必须承载业务语义（成功/警告/危险/信息）
2. **文化一致性原则**：遵循目标用户的文化习惯（如红色=危险/下跌，绿色=成功/上涨）
3. **色盲友好原则**：不依赖单一颜色传达信息，配合图标/文字辅助
4. **阈值可视化原则**：用特定颜色标记关键阈值线（如 --chart-target-line: #F53F3F）

**应用场景**：
- KPI 指标卡的趋势标识
- 告警系统的状态展示
- 数据阈值的视觉标记

**source_chapter**: 2.3 语义色 + 4.2 KPI Card

## P4: 响应式必做原则（Responsive Must-Do Principles）

**原文引用**：
> "移动端特殊行为: 柱状图转为水平柱状图, Legend 移至图表底部, Tooltip 固定于底部而非跟随手指, 触摸目标最小 44x44px"（来自 8.2 移动端特殊行为）

**原则清单**：
1. **断点适配原则**：至少定义 5 个断点（XL/L/M/S/XS），每个断点对应不同的布局
2. **交互优化原则**：移动端必须优化触摸体验（最小 44x44px）
3. **布局重排原则**：小屏幕下自动减少列数，必要时改变图表方向（纵向→横向）
4. **Tooltip 固定原则**：移动端 Tooltip 不跟随手指，固定于底部避免遮挡

**应用场景**：
- 任何数据可视化产品的多端适配
- Dashboard 的响应式设计
- 移动端图表交互优化

**source_chapter**: 5. Layout Principles + 8. Responsive Behavior

## P5: AI 迭代检查原则（AI Iteration Check Principles）

**原文引用**：
> "Iteration Guide: 1. 颜色第一位 2. 卡片是基本单位 3. Tooltip 不离散 4. 数据为空先处理 5. 移动端先考虑 6. 动画不超过 1 秒 7. 单位不可省 8. 图例排序与数据一致 9. 暗色模式双色板 10. 可访问性必检"（来自 9. Agent Prompt Guide）

**原则清单**：
1. **颜色优先原则**：生成图表前先确认用哪种色板（分类/顺序/语义）
2. **容器必包原则**：所有图表必须包裹在 .chart-card 容器中
3. **空数据处理原则**：检测空数据时自动渲染空状态占位，不渲染空白图表
4. **单位必显原则**：所有数值显示必须包含单位（万/亿/元/个/人/次）
5. **动画节制原则**：animationDuration 默认 800ms，首次加载可设 0
6. **可访问性必检原则**：色盲友好、对比度 ≥4.5:1、键盘可操作

**应用场景**：
- AI 生成代码后的质量检查
- 人工 Review 图表代码的清单
- 自动化测试的用例设计

**source_chapter**: 9. Agent Prompt Guide - Iteration Guide

## P6: 图表禁忌原则（Chart Taboo Principles）

**原文引用**：
> "Don'ts: 1. 不要使用超过 2 种字重 2. 不要在分类色板中使用相似度 >80% 的颜色 3. 不要隐藏轴刻度标签除非空间极度受限 4. 不要在饼图中使用 3D 效果或渐变填充 5. 不要在 Tooltip 中省略数据单位 6. 不要在 KPI 卡片中使用装饰性图表 7. 不要使用纯装饰性网格线 8. 不要在移动端展示超过 2 列的图表网格"（来自 7. Don'ts）

**原则清单**：
1. **字重限制原则**：图表中最多使用 2 种字重（避免视觉混乱）
2. **色距保障原则**：分类色板中相邻颜色的相似度 ≤80%（色盲用户可区分）
3. **刻度可见原则**：至少提供 3-5 个轴刻度标签，除非空间极度受限
4. **比例真实原则**：饼图禁用 3D 效果和渐变填充（扭曲数据比例感知）
5. **单位必显原则**：Tooltip 中必须包含数据单位（避免歧义）
6. **功能优先原则**：KPI 卡片中的微型图表只放于有趋势意义的指标（非装饰）
7. **网格极简原则**：仅 Y 轴需要分割线，X 轴和纯装饰性网格线禁用
8. **移动端密度控制原则**：移动端图表网格不超过 2 列（避免信息过载）

**应用场景**：
- 设计评审时的负面清单检查
- 自动化 lint 工具的规则配置
- 新人培训的反面教材

**source_chapter**: 7. Don'ts
